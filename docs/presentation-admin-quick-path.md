# Presentation admin quick path

1. Open `/settings/features` and keep **presentation demo** enabled.
2. Open `/game-control` and mark the games that should appear as **Featured**, **Popular**, or **New**.
3. Open `/game-assets` to configure shared game/provider images and optional PC/Mobile overrides.
4. Open `/content-center` or `/promotion-operations` to replace demo media with real campaigns.
5. Preview both Desktop and Mobile Member surfaces before disabling presentation mode.
